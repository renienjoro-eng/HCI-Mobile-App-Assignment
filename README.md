# 1. Introduction

The **University Student Portal Mobile App** is a Human–Computer Interaction (HCI) project developed by **Group 1** to design a simple, accessible, and user-friendly mobile interface for university students.

University students regularly need to access important academic and administrative services such as course registration, fee statements, academic results, and student profile information. A mobile student portal can bring these services together in one convenient platform, making it easier for students to complete common tasks using their smartphones.

This project focuses on understanding the needs of university students and applying HCI principles to develop an effective mobile user experience. The design process includes user research, identification of target users, development of user personas, creation of user journeys and task flows, low-fidelity sketches, Balsamiq wireframes, usability testing, and iterative design improvements.

The proposed mobile application provides a centralized interface through which students can access essential university services. The design emphasizes **simplicity, consistency, clear navigation, accessibility, feedback, error prevention, and ease of use**.

The final prototype demonstrates how a university student can use a mobile device to access key services such as course registration, fee statements, academic results, and student profile management.

# 2. Project Overview

The **University Student Portal Mobile App** is a mobile application prototype designed to improve students' access to common university academic and administrative services through a simple, centralized, and user-friendly smartphone interface.

The project focuses on applying **Human–Computer Interaction (HCI)** principles to the design of a mobile student portal. The prototype is developed using **Balsamiq**, while **GitHub** is used for collaboration, project documentation, version control, contribution tracking, and submission.

The application provides students with convenient access to essential university services, including:

* Course registration
* Fee statements
* Academic results
* Student profile management
* Navigation between key student services

---

# 3. Problem Statement

University students regularly need to access several academic and administrative services, including course registration, fee statements, academic results, and personal profile information. When these services are difficult to access or are presented through complicated interfaces, students may experience delays, confusion, and difficulty finding the information they need.

Students who primarily rely on smartphones need a convenient way to access important university services without having to navigate complicated systems or use multiple platforms.

The **University Student Portal Mobile App** is proposed as a centralized mobile solution that brings common student services together in one simple and intuitive interface. The application allows students to access course registration, fee statements, academic results, and student profile services while providing clear and consistent navigation.

The design focuses on improving the overall student experience through effective mobile interaction design, information architecture, consistency, usability, and user-centered design.

# 8. HCI Design Focus

The project applies several Human–Computer Interaction principles.

## 8.1 Mobile Navigation

The application uses clear navigation to help students move between major services.

## 8.2 Information Architecture

Information is organized into logical categories so that students can quickly locate the service they need.

## 8.3 Consistency

Buttons, menus, labels, layouts, icons, and navigation patterns are designed consistently throughout the application.

## 8.4 User-Centered Design

The design is based on the needs and expectations of university students.

## 8.5 Usability

The interface is designed to make common student tasks simple, understandable, and efficient.

## 8.6 Visibility of System Status

The interface provides feedback so that users understand what is happening after performing an action.

## 8.7 Error Prevention

The design reduces the possibility of errors during important activities such as course selection and registration.

## 8.8 Touch-Friendly Interaction

Controls and navigation elements are designed for interaction on smartphone screens.

The assignment specifically identifies mobile information architecture, navigation, consistency, interaction design, and usability as the HCI focus for this project.
