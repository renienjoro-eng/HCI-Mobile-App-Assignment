# Folder Organization

## Maintained by Joseph Nyori

This file documents the project folder organization for the HCI Mobile App Assignment.

## Repository Structure

- `docs/` — project documentation, requirements, personas, task flows, and supporting documents.
- `research/` — user research questionnaire, interview evidence, and research findings.
- `wireframes/` — low-fidelity sketches, Balsamiq screens, and prototype evidence.
- `usability-testing/` — usability testing tasks, participant notes, observations, and findings.
- `iterations/` — before-and-after evidence of design improvements.
- `final/` — final prototype evidence, presentation files, and final report materials.

## Coordination Notes

- Group members should upload evidence into the correct folders.
- Existing files should not be overwritten without discussion.
- New versions should use clear file names.
- Final presentation materials should be placed in `final/presentation/`.
