# Usability Test Tasks

## Testing Overview

- **Number of users:** 5 representative university students
- **Method:** Task-based usability testing
- **Duration:** 10–15 minutes per session
- **Location:** University campus / online

## Test Tasks

Complete each task on the Balsamiq prototype. Observe whether the user can complete the task, how long it takes, and whether any errors occur.

### Task 1: Logging in

- [ ] Ask the user to log into the student portal using their student credentials.
- **Observe:** Can they find the login screen? Do they enter credentials correctly? Any confusion?

### Task 2: Finding course registration

- [ ] Ask the user to navigate to the course registration service from the dashboard.
- **Observe:** Can they find course registration? How quickly? Any hesitation?

### Task 3: Selecting courses

- [ ] Ask the user to browse available courses and select required courses.
- **Observe:** Can they browse and select? Any confusion about course availability?

### Task 4: Completing course registration

- [ ] Ask the user to review their selected courses and confirm registration.
- **Observe:** Do they review before confirming? Do they understand the confirmation step?

### Task 5: Viewing fee statements

- [ ] Ask the user to navigate to the fee statement and view their balance.
- **Observe:** Can they find fee statements? Do they understand the fee information?

### Task 6: Checking academic results

- [ ] Ask the user to view academic results for a specific academic period.
- **Observe:** Can they select the period? Do they understand the results shown?

### Task 7: Viewing student profile

- [ ] Ask the user to view their student profile and any available profile information.
- **Observe:** Can they find the profile? Is the information easy to read?

### Task 8: Navigating between major services

- [ ] Ask the user to move between Home, Courses, Fees, Results, and Profile using the navigation.
- **Observe:** Is navigation intuitive? Can they return to the dashboard from different services?

## Evaluation Metrics

Record the following for each task:

- **Task completion:** Yes / No
- **Time on task:** ___ seconds/minutes
- **User errors:** Describe any errors or hesitations
- **Navigation difficulties:** Describe any confusion finding screens
- **Understanding of labels and controls:** Were labels clear?
- **Ease of completing tasks:** Was the task easy or difficult?
- **User feedback:** What did the user say about the experience?
- **Overall usability:** Rate 1–5
