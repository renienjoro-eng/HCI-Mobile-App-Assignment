# Design Iterations — Before & After

## Overview

Evidence of iterative design improvements based on user feedback.

## Folder Structure

- **before/** — Balsamiq screens before usability testing / user feedback
- **after/** — Updated Balsamiq screens after applying changes

## Iteration Process

Followed the assignment iteration cycle:

```text
Initial Sketches
     ↓
Balsamiq Prototype
     ↓
Prototype Walkthrough
     ↓
Usability Testing
     ↓
Identify Usability Problems
     ↓
Modify Design
     ↓
Improved Prototype
```

## Focus Areas

- Navigation consistency
- Information organization
- Button placement
- Screen layout
- Feedback and confirmation messages
- Error prevention
- Touch interaction
- HCI principles applied

## How to Add Evidence

1. Take a screenshot of the Balsamiq screen before changes → save to `before/`
2. Apply the design change based on feedback
3. Take a screenshot of the updated screen → save to `after/`
4. Name files clearly (e.g., `before-login-screen.png`, `after-login-screen.png`)
5. Describe the change in the filename or a companion note
